# Power BI dashboard — Brisbane rents: asking vs signed

## Quick start: open the ready-made project

`pbip/RentDashboard.pbip` is a Power BI Project (PBIP) generated by `build_pbip.py`:
the semantic model is TMDL (tables, relationships and the measures in `measures.dax`), the report is PBIR (4 pages).
Both are plain text, so they diff cleanly in git.

1. `python scripts/export_marts.py` (refresh the CSVs in `powerbi/data/`)
2. Open `powerbi/pbip/RentDashboard.pbip` in Power BI Desktop → **Refresh**
3. After changing the model or layout in code: `python powerbi/build_pbip.py`, then reopen the project.
   If you edit in Power BI Desktop instead, save there and stop using the generator (or port your
   changes back into it); otherwise the next run of the generator overwrites them.

The generator picks the default quarter on the gap page as the latest quarter with a same-quarter RTA
comparison, and the default suburb on the trend page as Toowong.

Checked in Power BI Desktop (Nov 2026) against section 4 below: QLD median $650 / +8.3%,
Toowong $559 / +7.7% / −14.0% vs QLD, Toowong mix-adjusted gap 7.8%, all-tracked gap −8.0%.

The rest of this file documents the design, in case you want to rebuild it by hand or extend it.

Files in this folder:

| File | What it is |
|---|---|
| `data/*.csv`, `data/manifest.json` | Mart exports from `python scripts/export_marts.py` (git-ignored) |
| `power_query.m` | One M query per table: CSV mode (default) or Postgres mode |
| `measures.dax` | Every measure, with the reasoning in comments |

Build time: about 2–3 hours for the first version.

## 1. Load the data (≈15 min)

1. Power BI Desktop → **Transform data** → **Manage Parameters → New**: `DataFolder` (Text) =
   `E:\project\QLD-rent-analysis\rent-pipeline\powerbi\data`.
2. For each section of `power_query.m`: **New Source → Blank Query → Advanced Editor**, paste and rename it
   exactly (`Gap`, `RtaLatest`, `RtaTrend`, `Velocity`, `Manifest`, `DimSuburb`, `DimDwelling`, `DimQuarter`).
3. **Close & Apply**. Expected row counts with the demo data: RtaTrend 200,625 · RtaLatest 1,870 · Gap 240 ·
   Velocity 591.

## 2. Model (≈15 min)

Star schema. All relationships **one-to-many, single direction, dimension → fact**:

```
DimSuburb[area_name]      ─┬─► RtaTrend[area_name]
                           ├─► RtaLatest[area_name]
                           ├─► Gap[rta_suburb]
                           └─► Velocity[rta_suburb]
DimDwelling[dwelling]     ─┬─► RtaTrend / RtaLatest / Gap / Velocity [dwelling]
DimQuarter[quarter_end]   ─┬─► RtaTrend / Gap / Velocity [quarter_end]
```

- Sort `DimDwelling[dwelling]` by `dwelling_sort`, and `DimQuarter[quarter_label]` by `quarter_index`.
- Hide every key column on the fact tables so report authors always slice by the dimensions.
- Data category: `DimSuburb[location_label]` → **Place** (helps the map geocoder).
- **Modeling → New parameter → Numeric range**: `Max RTA Lag`, 0–2, step 1, default 0.
- Create table `_Measures` and paste the measures from `measures.dax`. Formats:
  rents `$#,0`, % measures as Percentage with 1 decimal, Days on Market `0.0`.

> Why the measures look complicated: the marts store **medians**, which cannot be summed or averaged.
> One row in context → the published median; several rows → a weighted average of medians (by bonds or
> listings). 'All dwellings' is never added to the per-dwelling rows. Explaining this choice in an
> interview is worth more than any visual.

## 3. Pages

Theme: one accent colour for "asking" (Domain) and one for "signed" (RTA), used the same way on every page.
Put `[Data Banner]` (top) and `[Data As Of]` + `[Source Credit]` (bottom) as cards/text on every page.

### Page 1 — "Where rents are rising" (RtaLatest, all QLD)

| Visual | Fields | Notes |
|---|---|---|
| Slicer | DimDwelling[dwelling] | **Single select**, default "All dwellings" |
| Slicer | RtaLatest[new_bonds] ≥ 30 (filter pane, visual-level) | Hides tiny suburbs whose medians jump around |
| 3 KPI cards | `[QLD Median Rent]`, `[Signed Rent YoY %]` with DimSuburb unfiltered → shows QLD-wide weighted YoY; `COUNTROWS(RtaLatest)` = suburbs with data | Page filter: DimQuarter[quarter_end] = latest (Top N = 1 by quarter_end) |
| Azure Map (bubble) | Location: DimSuburb[location_label]; Size: RtaLatest[new_bonds]; Colour: RtaLatest[rent_yoy_pct] (diverging) | Tooltip: rent, YoY, 5y change, rank |
| Table | suburb, median_weekly_rent, rent_yoy_pct, rent_5y_pct, rent_rank_qld | Top 15 by YoY; data bars on YoY |

Use the **Azure Maps** visual: the old Bing-based Map/Filled Map visuals are being retired.

### Page 2 — "Trend vs Queensland" (RtaTrend)

| Visual | Fields |
|---|---|
| Slicers | DimSuburb[suburb] (default: `is_tracked = true`), DimDwelling[dwelling] |
| Line chart | X: DimQuarter[quarter_label]; Y: `[Signed Rent]`, `[QLD Median Rent]` (dashed) |
| Column chart | X: DimQuarter[quarter_label]; Y: `[New Bonds]` |
| Card | `[Signed Rent YoY %]`, `[Premium vs QLD %]` for the latest quarter |
| Small multiples (optional) | Line chart split by DimDwelling[dwelling_type] |

Add a text box: *"Compare year-on-year, not quarter-on-quarter: rents are seasonal (RTA guidance)."*

### Page 3 — "Asking vs signed" (Gap) — the headline page

| Visual | Fields | Notes |
|---|---|---|
| Slicers | DimQuarter[quarter_label], DimDwelling[dwelling], `Max RTA Lag` | |
| Card | `[Gap %]` + `[RTA Quarter Compared]` underneath | "Landlords are asking X% above what tenants sign for" |
| Clustered bar | Y: DimSuburb[suburb]; X: `[Asking Rent]`, `[Signed Rent]` | Sort by `[Gap %]` |
| Bar | Y: DimSuburb[suburb]; X: `[Gap %]` | Diverging colours: above 0 vs below 0 |
| Matrix | Rows suburb, columns dwelling, values `[Gap %]` | Conditional formatting; blank = suppressed by RTA |
| Card (warning) | `[Low Sample Rows]` | Conditional: show only when > 0 |

`Max RTA Lag = 0` gives like-for-like quarters only. The current quarter appears only at lag ≥ 1,
because RTA publishes about a month after quarter end.

### Page 4 — "How fast places lease" (Velocity)

| Visual | Fields |
|---|---|
| Line | X: Velocity[month_start]; Y: `[Days on Market]`; Legend: DimSuburb[suburb] (≤5 suburbs) |
| Bar | Y: suburb; X: `[Price Cut %]` |
| Scatter | X: `[Gap %]`; Y: `[Days on Market]`; Details: DimSuburb[suburb]; Size: `[Listings Closed]` |

The scatter tests one hypothesis: *do suburbs where landlords ask more above market take longer to
lease?* If the dots slope up, that is your insight. If they don't, say so.

## 5. Real-data finding to keep for the write-up

In Toowong (Sep Qtr 2026), **618 of 870** new bonds are dwelling type "Other", and the 'All dwellings'
median ($559) is *below* the 1-bedroom flat median ($600). Near UQ, a large share of tenancies are
probably rooms or student accommodation. That is why headline gaps must be mix-adjusted, and it is a
good story for an interview.
